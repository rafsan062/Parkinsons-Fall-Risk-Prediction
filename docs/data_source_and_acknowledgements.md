# Data Source and Acknowledgements

## PPMI data source

This project uses clinical data from the Parkinson's Progression Markers
Initiative (PPMI) database. The raw PPMI CSV exports reproduced in this
repository have filenames dated 24 August 2026; see [`data/README.md`](../data/README.md)
for the preserved source-file inventory and checksums.

PPMI's publication policy asks authors to include this data-source statement,
with the actual data-download date inserted before presenting or publishing:

> Data used in the preparation of this article were obtained on
> **[YYYY-MM-DD]** from the Parkinson's Progression Markers Initiative (PPMI)
> database (www.ppmi-info.org/access-data-specimens/download-data),
> RRID:SCR_006431. For up-to-date information on the study, visit
> www.ppmi-info.org.

The dated filenames do not independently establish the download date. The
presenter should replace the bracketed field with the actual PPMI data-download
date recorded for the submission.

## PPMI funding acknowledgement

PPMI specifies the following funding acknowledgement for posters and
publications:

> PPMI - a public-private partnership - is funded by The Michael J. Fox
> Foundation for Parkinson's Research and funding partners, including
> **[the full current PPMI funding-partner list]**.

The complete partner list should be copied from PPMI's current official source
immediately before submission because it may change. It is intentionally linked
rather than reproduced here as a static list.

## Poster use

This page provides QR-linked detail and source references. It does not replace
the acknowledgement that PPMI requires within the poster itself. The PPMI
publication policy states that posters must identify PPMI as the data source and
acknowledge the study sponsor and partners.

For a space-limited poster, a compact on-poster line can be used alongside this
QR link:

> **PPMI data source:** Parkinson's Progression Markers Initiative database,
> RRID:SCR_006431 (www.ppmi-info.org).

Before submission, retain the full PPMI data-source and funding statements on
the poster or obtain written guidance from PPMI's Data and Publications
Committee for any shortened alternative.
