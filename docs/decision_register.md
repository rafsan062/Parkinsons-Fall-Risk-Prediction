## D01 — Representing Part III ON/OFF assessments

**Status:** Combined-state maximum frozen as the primary representation for the current final run on 21 September 2026; separate ON/OFF remains an experimental alternative and the longer-term clinical preference remains open. Question drafted for Professor Lin, not sent.

**Verified evidence (14 September 2026):**

- The preserved legacy `Model_Development.ipynb` (zero-based code-cell positions 38 and 43) and `Model_Development.py` (lines 647–666 and 738–769) load `MDS-UPDRS_Part_III_26Jan2026.csv`. The active code sorts by patient and month, then takes the last nonmissing gait, postural-stability, Hoehn–Yahr, and Part III total values per patient. `NewFeatures.ipynb` uses the same approach for the three individual measures.
- These extraction blocks do not choose by `PDSTATE` or examination time. Tied month-level dates have no explicit clinical tie-breaker. The code does not average ON/OFF scores or explicitly delete one state. Per-feature selection can draw from different examinations when missingness differs.
- A maximum-based Part III total calculation appears in comments in the legacy model-development files; it is not the active calculation. Source inspection establishes preserved code behavior, not which historical version produced every reported result or why the authors chose it.
- The revision extraction instead uses per-field maxima within eligible patient/month groups and historical maxima for these Part III scores. It does not preserve ON/OFF as separate predictors. Neither approach guarantees a single coherent examination across all selected features.
- Local PPMI codebooks define `PDSTATE` as functional state at examination. The [official PPMI clinical forms](https://www.ppmi-info.org/sites/default/files/docs/AM3PPMIClinicalCRFPacket20250806.pdf) provide for OFF and ON examinations within a visit for treated participants. These can be distinct legitimate assessments, not duplicate entries.

**Concise question for Professor Lin:**

> Professor Lin, PPMI can record both ON and OFF motor examinations at the same visit. In the preserved legacy code, gait, postural stability, Hoehn–Yahr stage, and the Part III total are selected as the last available values without distinguishing ON from OFF. Was there a clinical reason for this approach? For the new model, should we retain ON and OFF measurements separately, or use a specified state?

**Decision / rationale:** Retain maximum valid pre-landmark values per Part III feature across states as a provisional baseline for near-term progress and comparison. This does not approve wholesale reuse of cleaning logic or settle the final ON/OFF representation. If retaining both is supported, later define timing, missing-state handling, and representation while preserving one analysis row per patient and the landmark cutoff. Do not choose a rule from held-out test performance.
