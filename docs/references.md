# References

This page provides the QR-linked literature and resource citations for the
project poster. It preserves the reference list from the archived revised
Parkinson's disease manuscript and adds the foundational SHAP reference used
for the poster's explanation figures. The current poster does not use numbered
in-text citations; the numbering below provides a stable list for readers.

For the PPMI data-source statement, funding acknowledgement, and publication
requirements, see [Data Source and Acknowledgements](data_source_and_acknowledgements.md).
